# Проверка связи с Пито

После серво начинается проверка 100 попыток чтения: 5 блоков по 20, целевой период 5000 мкс (200 Гц), I²C 400 кГц. Вывод журнала и экрана между блоками не входит в измеряемое расписание.

Датчик 0x28 должен вернуть 4 байта и статус 0 (свежие данные). Неполный пакет, тайм-аут, старые данные (статус 2), fault (3), иной статус или сбой тайминга считаются ошибкой. Wire ограничен тайм-аутом 3000 мкс. Частота восстанавливается перед чтением после возможного сброса Wire.

kLinkDiagnosticMode=true завершает все попытки с накоплением ошибок. Для перехода к нулю нужны все 100 успешных чтений. false останавливает этап на первой ошибке. Сбой расписания прекращает оба режима.

Журнал LINK содержит state, error, ok, attempts, missed, bus, timeout, status и rx. Отдельные расширенные поля и медленная диагностика включаются настройками, но требуют проверки размера Flash. На экране при ошибке — БРАК и причина, при успехе автоматически начинается ноль.
