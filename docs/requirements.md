# Итоговый сценарий и критерии

Текущий объём проекта завершён: автономная последовательность без кнопок, русский OLED-интерфейс, журнал Serial 115200 бод и полный повтор после переподключения Пито.

Порядок: серво → связь → ноль → поток → максимальная скорость → возврат → итог. При провале Пито следующие этапы не выполняются, на экране БРАК и причина. В диагностическом режиме связи все 100 попыток завершаются с накоплением ошибок; хотя бы одна ошибка запрещает переход к нулю. Сбой расписания останавливает тест сразу.

| Проверка | Настройка по умолчанию |
|---|---|
| Серво | D7, нейтраль 92°, пределы 20°/160°, шаг 1°, задержка 10 мс |
| Связь | 5 блоков по 20 попыток, 200 Гц, I²C 400 кГц, тайм-аут 3000 мкс |
| Ноль | 10 секунд, 50 Гц, окна по 1 секунде |
| Шум | Размах ≤30 Па, стандартное отклонение ≤5 Па |
| Дрейф | Размах средних окон ≤8 Па, модуль линейного тренда ≤0,8 Па/с |
| Поток | Модуль перепада ≥50 Па в течение 100 мс; подтверждение запоминается |
| Время потока | До 10 секунд, успешный переход не раньше 4 секунд |
| Максимум | Расчётная пиковая скорость за этап потока, показ 5 секунд |
| Возврат | Модуль перепада ≤5 Па непрерывно 1 секунду, ожидание до 5 секунд |
| Автоповтор | После итога: 3 NACK адреса, затем 3 ACK, опрос каждые 250 мс |

Ноль фиксируется только после успешной проверки стабильности и не подстраивается при потоке/возврате. Скорость: v = √(2·|Δp|/ρ), ρ=1,225 кг/м³; при |Δp|≤3 Па отображается 0. По умолчанию м/с, альтернативно км/ч. Число выводится с точностью 0,1. Расчётная скорость не подтверждает метрологическую точность датчика.

Серво выполняет команды; оператор оценивает механическое движение. Наследуемая последовательность содержит команду 19° перед возвратом от нижнего предела 20° — это сохранённая особенность исходного проверенного прохода. Автоматического обнаружения заклинивания нет. Итог ОК относится к проверкам Пито и не заменяет визуальную оценку серво.

Пороги предварительные и задаются в cfg. Проект не содержит заводской процедуры приёмки, эталонной калибровки, звуковых сигналов или меню настроек. Изменение параметров требует повторной загрузки скетча.
