# Подключение

Целевая конфигурация прошивки: классическая Nano ATmega328P, 16 МГц; OLED SH1106 128×64 на аппаратном SPI; ASPD-4525 на I²C. Работа дисплея и движения серво подтверждена пользователем в этой конфигурации пинов. Точный производитель платы и модель серво не записаны.

| Узел | Сигнал | Пин Nano |
|---|---|---|
| Серво | Управление | D7 |
| OLED | DC / CS / RESET | D8 / D9 / D10 |
| OLED | MOSI / SCK | D11 / D13 |
| Пито | SDA / SCL | A4 / A5 |
| Пито | Адрес | 0x28 |
| Все узлы | Общая земля | GND |

OLED подключён к 5V. Устройство использовалось с кабельным питанием; точная разводка питания серво не зафиксирована. Источник питания серво должен соответствовать его модели, земля источника соединяется с GND Nano. При смене модулей сверить их допустимое питание и уровни сигналов.

Диапазон давления в коде −6894,76…+6894,76 Па (±1 PSI), передаточная функция типа A. Это конфигурация используемого теста; маркировку другого датчика нужно сверить перед подключением. Проверка подключения не является калибровкой по эталонному давлению.

D9 зарезервирован для CS дисплея: управление серво перенесено на D7. D13 занят SPI; мигание LED_BUILTIN в рабочем сценарии не используется. Звук и дополнительный выход D2 из старого скетча в текущий проект не включены.
