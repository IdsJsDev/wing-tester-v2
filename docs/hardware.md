# Аппаратная часть — черновик

Значения из старого кода не являются подтверждением текущего подключения.

| Узел / сигнал | В старом PITOT_SERVO_TEST | В новом устройстве |
|---|---|---|
| Контроллер | Уточнить вариант платы | Arduino Nano, вариант уточнить |
| Серво, сигнал | D9 | D7, подтверждено пользователем |
| Звук, tone() | D5 | Уточнить наличие и подключение |
| Дополнительный выход | D2, только pinMode | Назначение неизвестно |
| Светодиод | LED_BUILTIN | Уточнить использование с экраном |
| ASPD-4525 | I²C, 0x28, ±1 PSI в конфигурации | Подтвердить маркировку и диапазон |
| SDA / SCL | Wire, пины явно не указаны | Уточнить по варианту Nano |
| Экран | Отсутствует | SPI OLED 1,3″, маркировка «OLED v2»; контроллер и разрешение уточнить |
| Экран: SCK / MOSI / MISO | — | Заполнить по фактическим проводам |
| Экран: CS / DC / RESET | — | Заполнить по фактическим проводам |
| Перенесённый сигнал | Серво на D9 | Серво на D7 |
| Питание серво / датчика / экрана | Не описано | Напряжения, источник, общая земля — уточнить |

Сейчас устройство питается от кабеля; позже планируется отдельный блок питания. Кнопок нет. Уточнить, имеется ли в виду USB Nano и подключено ли питание серво к 5V Nano; не считать эти детали подтверждёнными.

До выбора библиотек и схемы нужно получить маркировку экрана, его разрешение, подписи контактов и номера пинов Nano. Отдельно проверить назначение LED_BUILTIN относительно выбранной SPI-разводки.

Пользователь указал подключение экрана к D8, D9, D10, D11, D13, GND (в сообщении «GRN») и 5V. Соответствие сигналов экрана этим пинам ещё не подтверждено. Контроллер нельзя определить только по размеру и надписи «OLED v2».

`old/1.ino` теперь сохранён. В нём выбран U8G2_SH1106_128X64_NONAME_F_4W_HW_SPI: SH1106 128×64, аппаратный SPI, полный буфер. По тексту строки предполагаются CS=D9, DC=D8, RESET=D10, но комментарии повреждены и объявление некорректно. Эти назначения требуют подтверждения на устройстве. Комментарий про SSD1306 противоречит выбранному SH1106; ориентир — конструктор и аппаратная проверка.

Модель серво можно временно оставить неизвестной, если известны рабочее питание и проверенная конфигурация старого тестера. Старые углы не расширять без подтверждения механических пределов.
