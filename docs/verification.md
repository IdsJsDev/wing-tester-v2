# Сборка и программные проверки

Целевая плата: классическая Nano ATmega328P, FQBN `arduino:avr:nano:cpu=atmega328`. Проверенная конфигурация: Arduino AVR Boards 1.8.8, U8g2 2.36.19, Servo 1.3.0. SPI и Wire входят в пакет платы.

В Windows скрипт автоматически ищет Arduino CLI в PATH или установленной Arduino IDE и AVR-компилятор в стандартной папке Arduino15. Библиотеки ищутся в Arduino/libraries в Documents и Arduino15/libraries.

```powershell
powershell -ExecutionPolicy Bypass -File scripts/check.ps1
```

При нестандартной установке передать пути:

```powershell
./scripts/check.ps1 -ArduinoCli 'C:/tools/arduino-cli.exe' -AvrCompiler 'C:/tools/avr-gcc/bin/avr-g++.exe'
```

Для ручной сборки из корня проекта, если CLI доступен в PATH:

```powershell
arduino-cli compile --fqbn arduino:avr:nano:cpu=atmega328 --build-path build/manual firmware/wing_tester
```

Если библиотеки установлены вне стандартной папки sketchbook, добавить `--libraries` с их путём. Загрузка на плату выполняется через Arduino IDE с выбранными портом и вариантом загрузчика.

Три файла tests/*_test.cpp используют static_assert и не требуют отдельного исполняемого тестового раннера:

| Проверки | Что проверяется |
|---|---|
| zero_statistics | Статистика шума, средние окон и линейный тренд на синтетических сигналах |
| flow_detection | Удержание условия, сброс при провале и запоминание подтверждённого события |
| reconnect_detection | Последовательности ACK/NACK, ошибки шины, отсутствие ложных повторов |

Невыполненное утверждение вызывает ошибку компиляции. Скрипт проверяет код возврата каждой команды и останавливается при ошибке. Артефакты записываются в build/verification, исключённый из Git.

Итоговая peak-speed-v1: Flash 30298/30720 байт, глобальная RAM 1130/2048 байт. Оставшиеся 918 байт RAM разделяют стек и динамические данные; это не измерение максимального использования стека. Включение дополнительной диагностики требует новой проверки размера Flash.

Программные проверки не моделируют питание, движение механики и все неисправности датчика. Пользователь подтвердил базовый полный цикл на устройстве. При изменении железа или порогов проверить реальные успех, отсутствие потока, возврат и переподключение.
