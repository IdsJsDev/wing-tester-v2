# Шаг 1: проверка экрана

Скетч: firmware/wing_tester/wing_tester.ino. Открывать именно этот файл в Arduino IDE; имя папки совпадает с именем скетча. Старые файлы не изменены.

Библиотека: U8g2 (сборка проверена с установленной версией 2.36.19). Предварительно выбрана классическая Arduino Nano, ATmega328P. Вариант платы и загрузчика подтвердить на устройстве; при загрузке использовать прежние рабочие настройки Arduino IDE.

Предварительные соединения по old/1.ino:

| Экран | Nano |
|---|---|
| CS | D9 |
| DC | D8 |
| RES | D10 |
| MOSI / DIN | D11 |
| SCK / CLK | D13 |

Экран настроен как SH1106 128×64. Подключение и контроллер ещё не подтверждены аппаратной проверкой.

## Что должно появиться

1. Рамка по краям, «ТЕСТ ЭКРАНА», «Шаг 1: демонстрация».
2. Крупное число и полоса прогресса от 0 до 100% примерно за 10 секунд.
3. Внизу сначала «Датчик не проверяем», затем «Экран читается?». Финальное изображение остаётся до Reset.

Проверить читаемость кириллицы, края рамки, отсутствие смещения, движение полосы и итог. Если экран пуст, прежде всего сверить CS/DC/RES и модель контроллера. Если изображение перевёрнуто — изменить kRotate180 в блоке настроек.

Настройки в начале скетча: пины, контраст, поворот, интервал обновления, время демонстрации. kZeroTestDurationMs=10000 подготовлен для будущего этапа нуля, сейчас не используется. Новые параметры датчика появятся вместе с соответствующими этапами. Датчик и серво в этом шаге не управляются.

## Проверено

- Компиляция arduino:avr:nano:cpu=atmega328, AVR core 1.8.8: успешно.
- Flash: 15860 / 30720 байт (51%).
- Глобальные данные RAM: 574 / 2048 байт (28%); стек и локальные переменные используют оставшуюся память.
- Загрузка и изображение на устройстве: ещё не проверены.

Шаг завершится после подтверждения изображения пользователем. Затем добавляем только проверку связи с датчиком.
