# Экран

Используется U8G2_SH1106_128X64_NONAME_1_4W_HW_SPI: SH1106 128×64, страничный буфер 128 байт, аппаратный SPI. CS=D9, DC=D8, RESET=D10; MOSI=D11, SCK=D13. Контраст 180, стандартная ориентация, поворот задаётся kRotate180.

Один компактный кириллический шрифт 9×15 обслуживает интерфейс. Крупные ОК и БРАК рисуются небольшими шаблонами букв без второго большого шрифта. Во время измерений экран обновляется по страницам при достаточном запасе до следующего чтения.

Для серво экран рисуется один раз до движения и остаётся неподвижным. Максимальная скорость также показывается статичным кадром 5 секунд. Работа базового интерфейса и статичного экрана серво подтверждена пользователем.

Загрузка и версии библиотек описаны в README.md; детали сборки в verification.md.
