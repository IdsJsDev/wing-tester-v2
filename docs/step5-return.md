# Шаг 5: возврат к нулю и итог

После подтверждённого потока программа автоматически показывает «Не дуйте». Оператор прекращает поток; на экране остаются текущая расчётная скорость, спиннер и обратный отсчёт. Тот же страничный вывод с приоритетом чтения датчика, 50 Гц.

## Настройки

- kReturnWaitMs=5000: время ожидания, мс, с момента вывода инструкции.
- kReturnHoldMs=1000: непрерывное нахождение в полосе нуля, мс.
- kReturnBandPa=5.0: допустимый модуль перепада относительно сохранённого нуля, Па.

Допуск предварительный, подбирается на датчиках. Ноль берётся только из успешного 10-секундного этапа стабильности и не обновляется после потока. Зона отображения нулевой скорости 3 Па и диагностический допуск возврата 5 Па — разные параметры: условие проверяется непосредственно по давлению.

При abs(давление−ноль)<=5 Па начинается выдержка. Выход за полосу сбрасывает выдержку. Через одну непрерывную секунду в полосе весь цикл Пито считается пройденным: крупное «ОК», внизу «Тест пройден». При отсутствии устойчивого возврата за 5 секунд — общий «БРАК / Нет возврата к нулю». Ошибка чтения или расписания немедленно завершает тест с конкретной причиной. Итог остаётся до Reset или [подтверждённого переподключения Пито](reconnect.md). Серво по-прежнему отключено.

Serial: BOOT wing-tester return-v1; строка RETURN passed/n/dp_pa/peak_pa. peak_pa относится только к этапу возврата, dp_pa — знаковый перепад к фиксированному нулю. При провале RETURN_FAIL reason. Ошибки чтения дополнительно READ error/status/rx.

## Проверки

Сборка Nano ATmega328P успешна: Flash 29244/30720 байт (95%), глобальная RAM 1088/2048 байт (53%). Проверки FlowDetection через static_assert дополнены устойчивым возвратом и кратким пересечением нуля с выходом из полосы. Это проверки логики удержания, не аппаратуры.

Аппаратный прогон:

1. Без потока пройти связь и ноль.
2. На «Дуйте» коротко подать поток, наблюдать скорость. Подтверждение за 100 мс запоминается и меняет подсказку на «Принято»; переход не раньше 4 секунд. Продолжать дуть до конца этапа не требуется.
3. На «Не дуйте» прекратить поток. Ожидается итог ОК после устойчивого возврата.
4. При отдельном прогоне продолжать поток после «Не дуйте»: ожидается БРАК по тайм-ауту возврата.
5. Сообщить читаемость нового макета, итог и строки FLOW/RETURN.

Макет и весь цикл возврата ожидают аппаратного подтверждения. Если исправный датчик не укладывается в полосу, сначала оценить dp_pa и стабильность нуля, затем обоснованно корректировать параметры.
