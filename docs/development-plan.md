# Завершение текущего объёма

Проект завершён по решению пользователя. Рабочий код находится в firmware/wing_tester, ветка main публикуется в GitHub. Дальнейшие функции не включены в текущий объём.

| Направление | Результат |
|---|---|
| OLED | SH1106 128×64, русский интерфейс, страничный буфер |
| Серво | Первый этап при включении и переподключении; экран статичный во время движения |
| Пито | Связь, шум/дрейф, поток, возврат и итог с причиной провала |
| Максимум | Пиковая скорость на 5 секунд перед новым окном проверки возврата |
| Повтор | Подтверждение отключения и подключения, новый полный цикл |
| Диагностика старта | Раннее отключение унаследованного watchdog, журнал MCUSR и метки этапов |
| Контрольные копии | reconnect-v2 и servo-first-v4, исходники и HEX |
| Документация | Актуальные подключение, настройки, сценарий и воспроизводимая сборка |
| Проверки | Компиляция Nano и три набора static_assert |

Пользователь подтвердил работу reconnect-v2 и servo-first-v4 на устройстве. После удаления перерисовки при движении серво пользователь сообщил «все ок». Затем добавлен экран максимальной скорости; он включён в итоговую сборку. Это не означает, что отдельно выполнена аппаратная матрица всех видов неисправностей датчика.

Причина прежних перезапусков аппаратно не установлена. Стабильная версия сохраняет раннее отключение watchdog и статичный экран серво. MCUSR=0 не исключает аппаратный сброс: загрузчик может очищать регистр.

Последняя сборка peak-speed-v1: Flash 30298/30720 байт, глобальная RAM 1130/2048 байт. Инструкция запуска всех программных проверок: verification.md. Старые промежуточные планы и диагностические режимы доступны в истории Git и ZIP контрольных копий.
