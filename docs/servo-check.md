# Серво — первый этап

Пользователь подтвердил работу servo-first-v4. Текущая peak-speed-v1 сохраняет описанный ниже тест серво и добавляет экран максимальной скорости после выдоха; подробности в peak-speed.md.

Текущая версия servo-first-v4 выполняет серво при включении/Reset и после подтверждённого переподключения Пито, затем запускает связь → ноль → поток → возврат → ОК/БРАК. kServoTestEnabled=true; false пропускает только серво.

После добавления анимации серво пользователь сообщил повторные BOOT и мерцание экрана. В v4 удалены servoWait и перерисовка OLED во время движения. Перед каждым проходом один раз рисуется полный экран: «ТЕСТ СЕРВО», разделитель, «Проход крыла», схема двустороннего движения и «Оцените ход». Экран остаётся неизменным до начала проверки связи с Пито. Причина аппаратных перезапусков пока не установлена; изменение устраняет постоянную перерисовку, но результат требует проверки на устройстве.

Восстановлены обычные delay() и ранее проверенные команды: D7, нейтраль 92°, пауза 500 мс, проход к 160°, обратно к 20°, возврат с 19° к 92°. Исходная особенность min-1 сохранена. kServoStepMs=10 задаёт задержку после команды в 1°. После прохода импульсы остаются в нейтрали. Нейтраль задаётся перед первым attach. Исходная логика old/PITOT_SERVO_TEST.ino и лицензия сохранены; обратной связи о положении нет, оценка механики визуальная.

Serial: BOOT wing-tester servo-first-v4, RESET mcusr=..., INIT oled_begin, INIT oled_done, SERVO begin, SERVO screen, SERVO active, SERVO done, INIT ready, затем LINK/ZERO/FLOW/RETURN. При переподключении RESTART pitot-connected предшествует повторному SERVO begin. RESET mcusr=0 не исключает сброс: загрузчик может очищать регистр.

Сборка Nano ATmega328P: Flash 30060/30720 байт, глобальная RAM 1130/2048 байт. После загрузки проверить неподвижный экран во время серво, плавность прохода, возврат в нейтраль, переход к Пито и полный повтор при переподключении.

Подтверждённая пользователем reconnect-v2 сохранена в checkpoints/reconnect-v2-working.zip (исходники, документы и проверки) и checkpoints/reconnect-v2-working.hex. В проекте нет Git-репозитория; это контрольная копия для возврата. В этой версии серво отключено.
