# Серво — первый этап

Серво запускается при включении/Reset и после подтверждённого переподключения Пито. Затем автоматически выполняется весь цикл датчика. kServoTestEnabled=true; false пропускает только этот этап.

Команды: D7, нейтраль 92°, пауза 500 мс, движение к 160°, обратно к 20°, возврат с 19° к 92°. Команда min−1 сохранена из исходного проверенного прохода. Шаг 1°, задержка kServoStepMs=10 мс. После прохода импульсы остаются в нейтрали. Командный угол не является измеренным положением.

Один полный кадр выводится до движения: «ТЕСТ СЕРВО», разделитель, «Проход крыла», схема двустороннего движения, «Оцените ход». SPI-отрисовки во время движения нет. Это заменило промежуточную анимацию, после которой пользователь сообщил мерцание и повторные загрузки; статичная версия servo-first-v4 подтверждена сообщением «все ок». Причина прежних сбросов аппаратно не установлена.

Serial: SERVO begin → SERVO screen → SERVO active → SERVO done. При повторе перед ними появляется RESTART pitot-connected. Успешная выдача команд не является автоматической проверкой заклинивания — оператор оценивает ход крыла визуально.

Исходная логика old/PITOT_SERVO_TEST.ino и уведомление о лицензии сохранены. Проверенная базовая версия доступна в checkpoints/servo-first-v4-working.zip и .hex; текущий код дополнительно показывает максимум после потока.
