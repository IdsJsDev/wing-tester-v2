# Реакция на поток

Экран «Дуйте» показывает текущую расчётную скорость, индикатор и оставшееся время. Давление читается 50 Гц относительно сохранённого нуля.

По умолчанию модуль перепада ≥50 Па должен удерживаться 100 мс. Подтверждённый выдох запоминается, поэтому краткий успешный выдох не нужно удерживать до конца экрана. Переход не раньше 4 секунд; отсутствие реакции за 10 секунд даёт БРАК. kFlowAllowNegative=true допускает обе полярности перепада.

Скорость вычисляется по v=√(2·|Δp|/1,225). При |Δp|≤3 Па отображается ноль. Единицы задаёт kSpeedInKmh; по умолчанию м/с, точность вывода 0,1. Максимум модуля перепада накапливается только за этот этап.

После успеха показывается максимальная скорость на 5 секунд (peak-speed.md), затем начинается отдельная проверка возврата. При ошибке чтения или тайминга тест останавливается сразу. Алгоритм подтверждения и запоминания проверяется tests/flow_detection_test.cpp.
