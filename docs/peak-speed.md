# Максимальная скорость после выдоха

После успешного этапа «Дуйте» статичный экран показывает «Максимальная / скорость», значение и единицы. Пик рассчитывается по максимальному модулю перепада давления относительно проверенного нуля, накопленному за этап потока. Формула и точность 0,1 совпадают с текущей скоростью. По умолчанию м/с, kSpeedInKmh=true переключает в км/ч.

Экран показывается 5000 мс после завершения его отрисовки; время задаёт kPeakSpeedDisplayMs. Во время показа датчик не опрашивается, максимум не обновляется. Затем начинается «Не дуйте» с новым расписанием и полным окном возврата 5 секунд.

Ошибка этапа потока сразу даёт БРАК, без экрана максимума. Каждый новый цикл измеряет пик заново. Текущая метка запуска — BOOT wing-tester peak-speed-v1. Показ максимума включён в итоговую сборку; отдельная аппаратная проверка этого экрана в журнале проекта не записана.
