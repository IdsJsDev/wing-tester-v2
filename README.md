# Тестер датчика Пито и серво крыла БПЛА

Статус: пользователь подтвердил работу servo-first-v4; контрольная копия в checkpoints/servo-first-v4-working.zip и .hex. Текущая peak-speed-v1 сохраняет серво первым этапом при включении/Reset и переподключении Пито и добавляет максимальную скорость на 5 секунд после выдоха, перед проверкой возврата. Новый экран требует проверки на плате.

Цель — создать с нуля новый тестер на Arduino Nano с подключённым SPI-экраном, проверкой серво и ASPD-4525. Старые прошивки служат источником проверенной логики, а не основой кода новой версии.
